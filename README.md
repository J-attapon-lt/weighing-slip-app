# Weighing Slip App

เว็บแอปสำหรับสร้างและพิมพ์ใบชั่งน้ำหนัก 9 ใบ ใช้ฟอนต์ TH Sarabun New/THSarabunNew และรองรับการ Save เป็น PDF ผ่านคำสั่งพิมพ์ของ browser

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy GitHub Pages

1. สร้าง repository ชื่อ `weighing-slip-app`
2. อัปโหลดไฟล์ทั้งหมดในโปรเจกต์นี้เข้า branch `main`
3. ไปที่ Settings > Pages
4. Source เลือก GitHub Actions
5. workflow จะ deploy อัตโนมัติ

URL จะเป็นรูปแบบ:

```text
https://J-attapon.github.io/weighing-slip-app/
```
